Create a responsive, modern web application for "Transform Church" that serves as a Leadership Training Platform. The platform needs a frontend user interface for students, an admin dashboard for tracking, and a backend database to manage users, progress, and content.

Use a clean, modern UI (Tailwind CSS preferred) with a welcoming, encouraging aesthetic suitable for a church leadership environment.

---

### 1. USER AUTHENTICATION & PROFILES
* **Sign Up / Login:** Users must be able to create an account and log in.
* **Data Fields:** Collect First Name, Last Name, Email, and Phone Number during registration.
* **Roles:** Implement two roles: "Student" (default) and "Admin".

### 2. STUDENT DASHBOARD & LEARNING TRACKS
The dashboard should display available training modules, including default tracks: *Overall Leadership*, *Youth Ministry*, and *Kids Ministry*.

* **Assigned Modules Section:** At the top of the student dashboard, prominent placement should be given to modules specifically assigned to them by an Administrator.
* **Module Structure:** Each module contains a series of videos followed by a "Knowledge Check" (quiz).
* **Knowledge Checks:** Short multiple-choice quizzes graded on a Pass/Fail basis (e.g., 80% or higher to pass). Track and save this status per user in the database.
* **Video Queue:** Allow users to add specific training videos or entire modules to a personal "My Queue" list on their dashboard for quick access later.
* **Watch History:** Implement a "Watch History" section that logs which videos the user has watched, including a visual progress bar showing if a video is "In Progress" or "Completed".

### 3. ADMIN BACKEND VIEW
Create a secure Admin Dashboard accessible only to users with the "Admin" role.
* **User Management & Progress Matrix:** Display a list of all registered users with their contact details and a matrix showing their Pass/Fail status for each module's knowledge checks.
* **Module Assignment Feature:** Add the ability for an Admin to select a user (or multiple users) and formally assign a specific training module to them. The system should track the assignment date and due date (optional).
* **Content Management:** Provide a simple interface for Admins to add new training modules or tracks dynamically.

### 4. TECHNICAL STACK & DATABASE REQUIREMENTS
* **Frontend:** React, Vue, or HTML/JS with Tailwind CSS.
* **Backend:** Node.js (Express) or Python.
* **Database:** PostgreSQL or SQLite to persist data.
* **Schema Relationships:** * `User` table (storing profile data and role).
  * `Module`/`Video` tables (storing content).
  * `Assignments` table (mapping `User_ID` to `Module_ID`).
  * `WatchHistory` table (tracking `User_ID`, `Video_ID`, progress timestamp, and completion status).
  * `QuizResults` table (tracking Pass/Fail per user per quiz).

Please build the application scaffold, set up the database models, and create a beautiful, intuitive user experience for both church members and administrators.
